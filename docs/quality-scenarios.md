# Quality Attribute Scenarios

## 1. Security
**Scenario:** A malicious user tries to bypass login and access the exam.
**Response:** The system blocks access, logs the event, and notifies the admin.

## 2. Scalability
**Scenario:** 10,000 users join the platform at once.
**Response:** Load balancers distribute the load, ensuring smooth performance.

## 3. Availability
**Scenario:** One server fails during an exam.
**Response:** Backup nodes take over immediately with no interruption.

## 4. Usability
**Scenario:** A non-technical student takes an exam.
**Response:** The system guides them step-by-step with tooltips and help.
